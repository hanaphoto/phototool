# 撮影計算機

タイムラプス等の撮影に使う計算ツールです。単一HTMLファイル（`index.html`）で動作します。

公開URL（GitHub Pages）: https://hanaphoto.github.io/phototool/

## できること（3タブ）

共通設定として、フレームレート（24／30／60fps／自由入力）と撮影間隔（秒）を先に決めます。

1. **撮影時間を逆算** - 完成させたい再生時間（秒）を入れると、必要な枚数と必要な撮影時間を表示します
2. **再生時間を算出** - 撮影時間（時間＋分）を入れると、完成する再生時間、撮影枚数、秒換算を表示します
3. **バッテリー・カード** - バッテリー容量（mAh）と平均消費電流（mA）、メモリーカード容量（GB）と1枚あたりのサイズ（MB）を入れると、撮影できる時間、完成する動画の長さ、バッテリーで撮れる枚数、カードに入る枚数を表示します

- **ナイトモード**：夜間の撮影で眩しくならないよう、黒地に赤文字の表示へ切り替えます。通常表示は端末のライト／ダーク設定にも追随します

## 使い方

1. スマホやPCのブラウザで公開URLを開く
2. フレームレートと撮影間隔を設定する
3. 目的のタブを選び、数値を入れる（結果は入力に合わせてその場で表示されます）

## 注意

- バッテリーの結果は連続稼働の目安です。実際の持ちは温度や機材の状態で変わります
- カード容量は 1GB = 1000MB として計算しています
- 入力した数値は保存されません。ブラウザに記録する仕組みは無く、開くたびに初期値から始まります

## 仕様・プライバシー

- ファイルは `index.html` のみです
- フォント表示のため Google Fonts（Zen Kaku Gothic New）を外部から読み込みます。そのため完全なオフライン動作はしません（フォントが読めない環境では端末の標準フォントで表示されます）
- 計算はすべて端末の中で行い、入力値を外部へ送信する仕組みはありません。Service Worker は無いため、PWA（ホーム画面アプリ）としてのオフライン起動には対応していません
